OpenSesame–OSWeb MCP

Tools
Active
兩套 MCP server ，讓 AI agent 建構、驗證 OpenSesame/OSWeb 實驗並部署到 JATOS伺服器，由研究者把關每項關鍵決策。
發佈於

2026年10月15日

私人 repo，持續開發中 · 支援 OpenSesame · JATOS · Model Context Protocol

這套專案把「從實驗構想到線上收案」的完整流程包裝成 Model Context Protocol（MCP）工具。研究者以自然語言描述實驗、或直接提供預註冊內容，AI agent 就能讀寫 OpenSesame 的 .osexp 實驗檔、檢查 OSWeb 相容性、打包網頁版實驗、在網頁瀏覽器中驗證，最後匯入 JATOS 伺服器取得任務連結；收集到的結果也能匯出為支援各式分析套件的 CSV格式。目標是建立可重複的「預先註冊 → 實驗腳本 → 線上研究」流程：機械性的工作交給 AI agent，研究者負責工作流程的每項決策。

系統由兩個完全獨立、由AI agent 協調的 MCP server 組成。Python server（約 35 個工具）負責實驗檔編修、inline script、OSWeb 與 ES5 相容性檢查、打包、JATOS 部署與結果匯出，並提供規劃表單流程，把結構化的研究規劃轉成實驗骨架；Node.js server 以 Playwright 無頭執行產出的 HTML，提供執行、截圖與互動式煙霧測試。部署這類不可逆的動作設有硬性安全閘，預設關閉、必須由人開啟；更新已部署的研究採就地更新，研究連結與已收集的資料都會保留；每一次部署決策都寫入稽核紀錄。

開發採規格先行：工具行為先寫成規格契約，再以測試驅動實作，Python server 目前通過近 1,000 項自動測試。整條流程已在實際的 JATOS 伺服器上完成端到端驗證，驗證用的是九個經典實驗作業，作為示範而非新研究。八項來自 Zwaan et al. (2018)（Psychonomic Bulletin & Review）重複驗證的心理學實驗：Simon 作業、Flanker 作業、動作促發、間隔效果、DRM 假記憶、聯想促發、重複促發，以及句圖驗證作業中的形狀模擬；第九項是改編 OpenSesame 官方 WCST 教學的威斯康辛卡片分類測驗。本機規劃表單介面，以及多個 session 同時進行時的受試者分派對抗平衡，仍在驗證中。工具組採用與 OpenSesame 相同的 GPL-3.0 授權。

維護狀態：Active——核心流程已完成，其餘功能驗證中；repo 目前為私人狀態。
